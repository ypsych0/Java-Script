# Repositório JavaScript

Bem-vindo ao meu repositório de **JavaScript**!

Este espaço é dedicado ao meu aprendizado e desenvolvimento na linguagem JavaScript, reunindo exercícios, estudos, projetos e práticas de programação.

O objetivo é aprimorar minhas habilidades em desenvolvimento web, compreender os fundamentos da linguagem e explorar suas possibilidades na criação de aplicações interativas e dinâmicas.

## ecnologias e ferramentas

- **JavaScript (JS)** – Linguagem principal.
- **HTML5** – Estruturação de páginas web.
- **CSS3** – Estilização e design.
- **Visual Studio Code** – Ambiente de desenvolvimento.
- **Git e GitHub** – Controle de versão e armazenamento dos projetos.

## Conteúdos estudados

- Introdução ao JavaScript;
- Variáveis (`let`, `const` e `var`);
- Tipos de dados;
- Operadores aritméticos e lógicos;
- Estruturas condicionais (`if`, `else`, `switch`);
- Estruturas de repetição (`for`, `while`, `do while`);
- Funções;
- Arrays e objetos;
- Métodos de manipulação de dados;
- Manipulação do DOM;
- Eventos e interatividade;
- Arrow Functions;
- JSON;
- Programação assíncrona;
- Promises e Async/Await.

## Objetivo

Desenvolver uma base sólida em JavaScript, compreender sua aplicação no desenvolvimento web e criar projetos que envolvam lógica de programação, interatividade e manipulação de elementos de páginas.
